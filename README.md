# Sunray-

A modern responsive landing page for Sunray Family Counseling.

## Overview

This repository contains a rebuilt static site for Sunray Family Counseling with:

- `index.html` — responsive homepage structure
- `style.css` — modern layout, typography, and mobile navigation
- `script.js` — small interactive menu toggle for mobile view

## Features

- clean hero section with call-to-action buttons
- service highlights and location overview
- contact section with client sign-in link
- responsive mobile-first design

## Preview

Open the project in VS Code and use the Live Server extension to preview the site locally.
